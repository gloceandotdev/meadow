# Meadow for Feishin

## Install

Custom themes only work in the desktop app.

1. In Feishin, open **Settings → General → Theme** and click **Open Folder** under **Custom Themes**.
2. Copy the files in `themes/` into that folder.
3. Pick **Meadow** or **Meadow Light** from the Theme dropdown. If they don't show up, click **Reload**.

The folder is usually here:

| Platform | Path |
|---|---|
| macOS | `~/Library/Application Support/feishin/Themes` |
| Linux | `~/.config/feishin/Themes` |
| Windows | `%APPDATA%\feishin\Themes` |
