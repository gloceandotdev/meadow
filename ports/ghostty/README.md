# Meadow for Ghostty

## Install

Copy the files in `themes/` into `~/.config/ghostty/themes/`, then add one of these to your Ghostty config:

```
theme = Meadow
```

```
theme = Meadow Light
```

Or let Ghostty switch between them with your system's appearance:

```
theme = light:Meadow Light,dark:Meadow
```

## Notes

The colors come straight from the terminal section of [palette.json](../../palette.json), so there's nothing extra to explain.
