# Meadow for Discord

## Install

You need a modded client, like [Vencord](https://vencord.dev) or [BetterDiscord](https://betterdiscord.app). Meadow works with Discord's dark themes and Meadow Light works with the light one, so you can turn both on and they will follow Discord's appearance setting.

### Vencord

Open **Settings -> Themes -> Online Themes** and paste these in, one per line:

```
@dark https://raw.githubusercontent.com/gloceandotdev/meadow/main/ports/discord/themes/meadow.theme.css
@light https://raw.githubusercontent.com/gloceandotdev/meadow/main/ports/discord/themes/meadow-light.theme.css
```

If you would rather use local files, click **Open Themes Folder**, copy the files in `themes/` into it, click **Load Missing Themes**, and turn them on.


### BetterDiscord

Open **Settings -> Themes**, click the folder button, copy the files in `themes/` into it, and turn them on.
